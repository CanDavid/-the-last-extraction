# Recursos

Sprites geométricos, terreno, iconos PNG, paisaje CSS y sonidos sintetizados: originales creados para The Last Extraction. No hay descargas de imágenes, fuentes, audio ni APIs en ejecución. Se utilizan fuentes del sistema.

Dependencias: Phaser 3 (MIT), Vite (MIT), TypeScript (Apache-2.0), Vitest (MIT), fake-indexeddb (Apache-2.0), Playwright (Apache-2.0), Prettier (MIT). Consultar licencias completas de los paquetes instalados. Las dependencias de desarrollo no se cargan en las partidas.
